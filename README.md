# Blume popo — He drowns in the She // Music Video v2（实时渲染 MV）

v1 是一本慢慢溺水的日系实验杂志。v2 让这本杂志真正掉进海里：纸页被撕开、被打湿、被海浪吞没，杂志后面是一片实时光线步进（ray-marching）渲染的 3D 海，海面和水下都能拍到。

- 排版、照片拼贴、孔版／胶印印刷模拟沿用 v1（Canvas2D + WebGL2）。
- 新增 3D 海、镜头系统和光字层。
- 画面素材换成 30 张 CC0 现代摄影（rawpixel），**全片不再用任何古典绘画**。

v1 原样保留在 `../he-drowns-mv`。

## 运行

1. 双击 `start.bat`（或 `node serve.js`，然后打开 `http://127.0.0.1:8181/`）。
2. 显示「準備完了」后点「▶ 再生 / PLAY」，按 `F` 全屏。

> 不能直接双击 `index.html`：用 file:// 打开时，浏览器禁止读取音频，也禁止把图片交给 WebGL。

推荐 Chrome / Edge。实测 1080p 每帧 1.5–11 ms，平均 6.4 ms（RTX 4060 Laptop，含 3D 海、印刷和后期）：

- 这是全曲 43 个采样点的稳态帧时间；
- 实时播放时音画漂移小于 1 ms，120–144 fps，无报错；
- 显卡较弱时按 `Q` 降到 900p / 720p。

## v2 改了什么

**1. 情绪递进：三个高潮，一次比一次大**

**镜头运动与抖动**（`js/camera.js`）：

- **`rumble`**（吉他音墙）：抖动幅度 ∝ 响度^1.4 的高频抖动，底鼓一下镜头往下顿、视角一冲，军鼓一下随机方向的横滚。
- **`handheld`**：慢速漂移。
- **`ride`**：让镜头骑在浪上。JS 端和 GPU 用同一套整数哈希的高度场，所以镜头的高度和倾斜与渲染出来的浪完全一致。
- **运镜手法**：推轨、升降、俯冲、绕转、180° 甩镜、穿过水线（画面上下分成水上 / 水下）、被浪托起、被浪吞没。
- 所有运动都是歌曲时间的纯函数，拖动、暂停、录制都严格同步。

**2. 现代素材**

30 张 CC0 现代摄影：水下人像、手与贝壳、绿眼、红唇插画、血月、东京夜景、空船、海浪（出处见文末）。

照片同时以三种方式出现：

- 印在纸上；
- 作为 3D 海里漂浮、下沉、被浪掀起的「卡片」（WebGL2 纹理数组，24 张）；
- 作为 1/16 拍的潜意识闪帧。

**3. 景深：从平面到 3D**

副歌和音墙几乎全部发生在 3D 海面上或海里，平面排版退成「光」浮在镜头前：

- 文字不再印成油墨，而是用 screen 混合作为光叠在画面上；
- 标注线跟着 3D 物体走，比如「波高」刻度计、「fig.19 — 彼」的引线、月亮周围的红圈、「此岸 — Tokyo, 38 km」的取景框。

## 3D 海（`js/sea.js`，一个片元着色器）

- **高度场**：TDM 风格的尖浪八度叠加，加上可移动的巨型涌浪（有方向、陡峭的前坡、可控波高）和最多 8 个水滴涟漪。
- **海面追踪**：单循环自适应步进 + 割线细化。从远处升起的 12 m 浪墙也能命中。
- **水面以上**：
  - 菲涅尔反射天空；
  - 月光闪烁路径；
  - 浪尖透光，月亮在浪后面时浪唇发青；
  - 碎浪泡沫，以及顺着浪面流下的泡沫条纹。
- **天空**：
  - 带纹理的月亮（血月照片，可在苍白月与红月之间切换）；
  - 星空和体积云；
  - 指向某一片天空的闪电，随军鼓闪；
  - 斜向雨丝；
  - 地平线上一段东京夜景，以及它在低云和雾里的橙色光晕。
- **水面以下**：
  - 斯涅尔窗（Snell's window）和全内反射；
  - 体积光柱；
  - 悬浮颗粒 / 气泡；
  - 深度衰减。
- **水线**：逐像素判断镜头在水上还是水下，镜头穿过水线时画面被一条弯月面分成两半。
- **卡片**：照片或印好的整页（先把纸面印到贴图上），作为矩形放进场景，水上水下都能看到。
- **多视口**：一帧最多 5 个机位，用于四宫格、五条、劈开的画面和杂志格子。
- **其他**：ACES 色调映射，线性空间计算，每个视口可单独调色。
- **编译**：KHR_parallel_shader_compile 异步编译；在音频加载的同时，按 ANGLE/D3D11 的编译耗时陷阱改写过循环和调用点。
- **海浪时钟**：对「0.35 + 1.15 × 响度^1.6」积分，乐队越响，浪越快。

**与印刷合成的三种方式**（`js/print.js`）：

- 纸上挖洞，从洞里看到未加网的真实 3D 海；
- 把 3D 当成一张照片，分色、加网点后印在纸上；
- 把整页印好，作为卡片漂进 3D 海里。

## 卡点

- **时钟**：Web Audio `getOutputTimestamp()`，已扣除输出延迟。所有画面都是「当前播放时间」的纯函数。
- **切镜位置**：
  - 小节强拍和节拍分组起点（3-3-3-3-4、5/8 的 4+6 / 4+3+3、2/4 每 2 个 16 分音符）；
  - 歌词逐字（按假名读音数拍），关键字落在被唱到的那一刻，例如「飲」时浪墙吞没镜头、「彼」时浪托到最高点。
- **打击乐包络**（每个 16 分格的强度经指数衰减）：
  - kick：页面冲击缩放、镜头下顿、镜头被按进水里、径向模糊；
  - snare：印版套印错位、横滚、闪电、水下光柱频闪；
  - hat：颗粒闪烁。
- **拍号可视化**：
  - 节拍尺；
  - 3:3:3:3:4 的五条；
  - 5/8 的五条横幅；
  - 10:10:10:12 的格子和 42 格刻度尺；
  - 3/8 的三个点；
  - 拍号角标。

## 音频分析（`tools/`，与 v1 相同）

- **原文件与解码**：WMA，用 imageio-ffmpeg 解码。
- **起音检测**：STFT → log-mel → SuperFlux 起音（四个频段）。
- **节拍网格**：Rayleigh 相位搜索出统一的 16 分网格，**91.000 BPM**（16 分音符 0.164835 s，原点 0.0788 s）。
- **拍号**：滑动自相关得出。
- **打击乐**：HPSS 分离后统计 kick / snare / hat。
- **小节线**：由 chroma 新颖度和歌词起点验证。

## 文件

```
index.html / style.css        页面与启动封面
serve.js / start.bat          本地服务器
js/main.js                    启动、加载、渲染循环（纸 / 3D / 合成三条路径）、控制、录制、测试接口
js/sea.js                     3D 海：光线步进着色器 + JS 端同一高度场（镜头骑浪用）
js/camera.js                  镜头：关键帧、手持、吉他墙抖动、骑浪、浮卡、投影、海的「样子」（calm/night/storm/red/warm/deep/abyss）
js/print.js                   印刷引擎（分色、网点、套印、负片、光字、3D 合成、径向模糊、拖影）
js/audio.js / timing.js       播放时钟、91 BPM 网格、变拍小节表、打击乐包络
js/lyrics.js / draw.js        歌词与读音、2D 排版工具
js/director.js                镜头表与潜意识帧
js/scenes/*.js                cover, shore, verseA, chorusA, wall, decon, cycle, verseB, chorusB, end
data/analysis.js / images.js  分析结果、图片清单、3D 卡片列表
tools/                        音频分析、素材下载与处理、字体子集化、无头浏览器截图 / 性能 / 播放测试
```

无头测试工具（Edge + DevTools 协议，无 npm 依赖）：

- `node --experimental-websocket tools/shoot.js --sheet=名字 t1 t2 …`：截帧并拼接触印样；
- `tools/playtest.js 秒数`：真实播放测试，检查漂移、帧率、报错；
- `tools/evaljs.js "表达式"`：在页面里执行，例如 `__mv.perf(t, n)` 测帧时间。
